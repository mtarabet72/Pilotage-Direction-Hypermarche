# Internationalisation (AR/FR)

## Modules traduits

Les éléments de traduction couvrent :

- navigation et vues
- écrans de connexion
- messages / toast
- filtres et labels de formulaire
- exports PDF et rapports

Les fichiers de référence sont :

- `../../src/i18n/fr.json`
- `../../src/i18n/ar.json`
- `../../src/i18n/i18n.js`

## Tableau des clés

| Module | Clé | FR | AR |
| --- | --- | --- | --- |
| navigation | `nav.dashboard` | Dashboard | لوحة القيادة |
| navigation | `nav.tasks` | Suivi Tâches | متابعة المهام |
| tâches | `tasks.empty` | Aucune tâche pour ce filtre. | لا توجد مهام لفلتر الحالي. |
| auth | `login.username` | Nom d'utilisateur | اسم المستخدم |
| export | `export.title` | Générer un rapport | إنشاء تقرير |

## Règles de formatage

Les valeurs numériques et temporelles doivent être formées via `Intl` selon la langue active.

```javascript
const dateFormatter = new Intl.DateTimeFormat(lang, { dateStyle: 'medium' });
const numberFormatter = new Intl.NumberFormat(lang, { maximumFractionDigits: 2 });
const percentFormatter = new Intl.NumberFormat(lang, { style: 'percent', maximumFractionDigits: 1 });
```

## Impact RTL

Les libellés arabes exigent des ajustements de direction de texte et de positionnement pour conserver une lisibilité parfaite en mode RTL.

Les composants sont conçus pour accepter :

- `dir="rtl"` sur le document
- alignement de texte `start` / `end`
- marges et paddings logiques
- inversion des éléments directionnels dans les composants graphiques
