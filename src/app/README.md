# Architecture modulaire

Cette structure est préparée pour la migration progressive du projet vers une architecture plus professionnelle.

## Dossiers

```text
src/
├── app/
│   ├── components/
│   ├── core/
│   ├── features/
│   └── services/
├── styles/
│   ├── design-system.css
│   └── app.css
└── scripts/
```

## Objectif
- séparer les composants UI ;
- structurer les vues de l’application ;
- centraliser les styles de base ;
- préparer la refonte du système visuel sans casser le comportement existant.
